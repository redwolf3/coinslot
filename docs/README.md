Where things go:

- **A decision with alternatives** (stack, schema, model, deployment): new ADR.
- **"What does X do / is Y possible"** (game logs, Windows APIs, measured data): analysis note.
- **How the system works now**: `design.md`. Update it in the same commit as the code.
- **What we'll build later**: `roadmap.md`.
